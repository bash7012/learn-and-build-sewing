A fitted block is not a garment. While I am still learning, I expect to use it two ways: as a check against a pattern I already have, and as a check against clothes that already fit.

I am keeping both branches together because they are the same skill from two starting points.

## When to use the block vs an existing pattern

- [ ] Decide when I should draft from the block
- [ ] Decide when I should grade an existing pattern between sizes
- [ ] Decide when I should trace something that already works
- [ ] Write the rule I actually follow after I have tried both onesie branches

## Tweaking or outlining an existing pattern between grades

This is the "I have a printed pattern, but my child sits between sizes" branch.

- [ ] Note which points the block says to move
- [ ] Note what I refuse to average blindly
- [ ] Check whether the graded outline still matches the body against the block

### What I compare

- [ ] Chest
- [ ] Length
- [ ] Shoulder
- [ ] Crotch or rise if relevant
- [ ] Ease

### What I change on the paper

- [ ] Blend between sizes where needed
- [ ] True the seams after blending
- [ ] Write down every move
- [ ] Do not average a point that is a full size off

## Altering a paper cutout traced from an existing garment

This is the "this onesie already fits, so I am taking a rubbing of it" branch.

- [ ] Choose the garment and why it fits (and what I already dislike)
- [ ] Trace carefully; note where seams hide the true shape
- [ ] Compare the rubbing to the block and to fresh measurements

### Tracing without wrecking the garment

- [ ] Plan how I trace without taking the garment apart for real
- [ ] Account for stretch in the worn cloth
- [ ] Add back seam allowances and closures on paper only

### Checking the rubbing against the block

- [ ] Mark where the worn garment has already eased
- [ ] Mark where it has stretched
- [ ] Mark where it has grown out of
- [ ] Carry surviving changes onto the paper pattern I will cut from
